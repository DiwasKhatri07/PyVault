# Code of Conduct

## Our standard

PyVault welcomes participation from people of all backgrounds. Contributors are expected to be respectful, constructive, and considerate in issues, pull requests, discussions, and other project spaces.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, sexualized conduct, deliberate disruption, and sharing private information without permission.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior violates this code. Report concerns privately to the maintainer through the contact method listed on the GitHub profile: [@DiwasKhatri07](https://github.com/DiwasKhatri07).

Reports will be handled as confidentially as practical. Please include links, dates, and any relevant context.
